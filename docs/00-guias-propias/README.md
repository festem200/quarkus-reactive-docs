# Guías propias (en español)

Material escrito para este repositorio. No es documentación oficial de Quarkus: es la
capa de organización, criterio y contexto que hace navegable el corpus oficial que está
en el resto de carpetas. Todo lo que se afirma aquí enlaza a la guía oficial que lo
respalda.

| Guía | Para qué sirve |
| --- | --- |
| [Ruta de aprendizaje](01-ruta-de-aprendizaje.md) | En qué orden leer las 140 guías oficiales, por niveles y con tiempos estimados |
| [El modelo de ejecución](02-modelo-de-ejecucion.md) | Qué hilo ejecuta tu código y qué puedes hacer en él: la regla que evita el 80 % de los problemas |
| [Chuleta de Mutiny](03-mutiny-chuleta.md) | Referencia rápida de `Uni`/`Multi` y sus operadores más usados |
| [Mejores prácticas](04-mejores-practicas.md) | Diez reglas de diseño con su justificación y su fuente oficial |
| [Antipatrones](05-antipatrones.md) | Los errores que se repiten, con el código malo, el bueno y el porqué |
| [Matriz de extensiones](06-extensiones-reactivas.md) | Qué extensión es reactiva y cuál bloqueante, por capa y por motor |
| [Checklist de producción](07-checklist-produccion.md) | Verificación previa al despliegue, en formato de lista marcable |
| [Glosario](08-glosario.md) | Vocabulario reactivo de Quarkus, Mutiny y Vert.x |
